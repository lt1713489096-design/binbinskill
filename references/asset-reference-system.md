## 冲突优先级

多份资产、剧本与提示词冲突时，按以下顺序决定：

1. 剧本事实、出场角色、时序、动作与道具归属。
2. 已绑定角色、场景和道具资产。
3. 前后镜的站位、视线、方向、造型、时间和光源连续性。
4. 当前 Shot 的画面任务、主体动作和景别。
5. 多张风格参考中重复出现的稳定共性。
6. 其他摄影、色彩、光效和装饰性细节。

不得为了更帅、更华丽或更有冲击力，改变人物身份、剧情动作、道具归属和时序。

## 参考资产分类

实际查看每份资产后，只给它分配清楚用途：

| 类型 | 锁定内容 | 不得推导 |
|---|---|---|
| 角色 | 身份、年龄、脸型、五官比例、发型、体态、服装层级、识别特征 | 参考图排版、当时表情和背景都必须复制 |
| 场景 | 空间结构、入口、关键物件、活动区、主光源和可重复机位 | 同一景别、同一天气或所有物件都必须入镜 |
| 道具 | 功能、尺寸、轮廓、材质、磨损、持握方式和当前状态 | 剧情未赋予的纹饰、发光或神性 |
| 风格 | 镜头、构图、光线、色彩、质感和氛围的呈现方法 | 参考图人物、建筑、动作和道具身份 |
| 色板 | 主色、辅色、点缀色及明度/饱和关系 | 直接复制全部内容和光效 |
| 构图 | 主体占比、视觉重量、留白和前中后景组织 | 替换剧情角色和空间事实 |

直接参考、风格提取和色板提取必须分开记录。

## 角色资产

多镜头反复出现的角色先建立统一资产，至少包含：

- 身份、年龄范围、生活状态和体态。
- 脸型、五官比例、发型、身高/体型和稳定识别特征。
- 默认服装层级、颜色、材质、旧化和常驻配件。
- 中性、喜悦、疑惑/思考、恐惧/担忧、坚定等可拍摄表情范围。
- 年龄、伤势、服装或发型发生剧情性变化时，建立有效时段明确的变体，不覆盖基础版本。

角色三视图/资产表用中性背景和稳定光线，不做英雄海报和剧情特效。

## 场景与道具资产

场景先建立可重复的空间，再写氛围：入口、路径、主要物件、人物活动区、主光源和 2–3 个可重复机位。雾、烟、粒子和光效不得遮住空间结构。

道具先写功能和尺寸，再写轮廓、材质、磨损、归属、持握关系和剧情状态。未在剧情中获得、打开、损坏或激活的道具，不得提前显示该状态。

## 风格参考共性

先逐张实际查看参考图。多张风格图只提取反复出现的稳定共性；只有一张时，降低对偶然内容的判断权重。

按六维提炼：

1. 镜头与画幅：比例、景别、机位、焦段空间感、景深和主体占比。
2. 主体呈现：主体大小、清晰/剪影、姿态强弱和细节集中区。
3. 环境与构图：前中后景、留白、引导线、对称/偏置和视觉重量。
4. 光线：主光方向、软硬、反差、环境反射光和互动光。
5. 色彩：冷暖、主辅色、点缀色、饱和度、明度及高光/阴影偏色。
6. 质感与氛围：写实/风格化程度、纹理、颗粒、镜头扩散和情绪强度。

参考图中独有的人物、建筑、动作和道具属于内容，不得写入风格共性。

## 多参考与能力降级

- 平台支持多参考时，按用途显式绑定，不只列文件名。
- 平台只支持一张参考时，优先保留当前 Shot/Clip 最难用文字稳定的硬资产；其他资产提取成简短文字锚点。
- 平台不支持参考图时，将身份、造型、空间和道具的最小区分特征写入提示词。
- 特写只绑定实际入镜资产；连续性资产可以约束空间，不强迫全部显示。

## 提示词可追溯性

实际生成前，先固定每个 Shot 关键图和每个 Clip 视频提示词的版本、参考映射、画幅、平台与输出位置。同一批次的提示词全部定稿后再生成，避免后续内容使用未记录的临时改动。

修订时：

1. 保留原提示词和失败表现。
2. 先写新版提示词及修订原因。
3. 使用新版本重生成受影响的 Shot/Clip。
4. 不重做没有受影响且已通过质检的 Shot/Clip。

不用程序在已生成位图上覆盖、重画或替换错误文字和主体构图。需要修复时更新提示词并重生成；裁剪、缩放、压缩和格式转换只能在不改变文字与主体构图时使用。

## 故障诊断

| 失败表现 | 首先检查 | 最小修复 |
|---|---|---|
| 人物身份/脸/服装漂移 | 角色参考用途、冲突外观词、变体时段 | 恢复硬参考，删除冲突重设计词 |
| 场景结构改变 | 入口、关键物件、主光源和重复机位 | 补齐场景结构锁定，减少氛围遮挡 |
| 道具变形/状态提前 | 功能、尺寸、归属、持握关系和剧情时序 | 恢复当前时点的道具状态 |
| 参考图失效 | 平台参考能力、映射是否明确、文字是否冲突 | 优先保留最难文字化的硬资产，其余改成锚点 |
| 风格不统一 | 是否混入单张偶然内容或冲突风格 | 只保留多图共性，删除独有内容 |
| 画面脏暗/主体不突出 | 光源、环境反射光、背景纹理和视觉重量 | 补合理反射光，降低背景频率，用明暗/色彩/景深分离主体 |
| 画面像海报而不像剧情 | 是否正面摆拍、英雄低机位、无动作起点 | 回到剧情动作瞬间，恢复关系和空间任务 |
| 视频漂移/融化/乱运镜 | 主体动作数、运镜数和稳定约束 | 减少动作和运镜，补身份/空间/光源锁定 |
| 字幕/文字不可读 | 移动端安全区、背景对比、字数和生成文字风险 | 优先后期添字，重生成干净留白画面，不在位图上覆盖修补 |
