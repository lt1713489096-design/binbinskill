# 关键图克制与修复

## 适用范围

用于编写、生成、检查或修复 Shot 关键图。重点处理画面杂乱、主次不清、光线无来源、颜色过多、人物僵硬、AI 海报感和 CG 感。它只优化静态起点，不替代剧情节拍、导演调度、参考资产、轴线、动作过程或 Clip 视频提示词。

## 优先级

按以下顺序决策：

1. 剧情事实、导演意图和 Asset 硬锁定。
2. 人物关系、空间、道具状态和连续性。
3. 画面主核与观看顺序。
4. 光线、色彩和成像响应。

不得为了“更电影”改变角色身份、服装、人数、剧情道具、场景结构或既定画幅。项目画幅优先；未指定时仍使用 `9:16`。

## 画面主核

先用一句可见事实锁定：

```text
谁/什么，在什么环境里，处于什么可见状态或瞬间。
```

画面主核必须对应本 Shot 的画面任务和动作起点。逐项检查人物、道具、前景、背景、天气、粒子、光源和装饰：不能支持主核、连续性或必要空间信息的内容删掉。

## 复杂度预算

默认只保留：

- 一个主要视觉焦点；焦点可以是一人、两人关系、群体关系或关键道具，不机械限制人数。
- 一个主要状态或动作起点。
- 零到一个推动剧情或定位空间的关键道具；剧情要求多个时保留并分主次。
- 一个主要环境和一种前景组织手段。
- 一个有来源的主光；环境辅光只负责可读性，不与主光竞争。
- 一个主色关系和最多一个辅助色关系。
- 一种成像响应；相机或胶片名称只在确有帮助时作为可选描述。
- 三条以内针对当前失败的负面约束。

例外：群像、复杂空间建立、证据集合或多人物权力关系需要更多元素时，可以超过默认预算，但必须写明每个元素的剧情功能和观看顺序。

## 人物状态

只写当前瞬间最重要、模型可观察的状态：视线、头部方向、重心、姿势、手部与道具关系。避免同时堆叠多个微表情、连续动作和抽象心理词。

双人或多人镜头以关系为视觉焦点，明确谁占主导、谁先被看见、距离和遮挡如何表达关系，不把配角误删成“多余人物”。

## 光线与色彩

- 写明主光来源、方向和软硬，例如窗外阴天漫射光、画面左侧路灯半硬侧光。
- 暗部保留可读层次，取消无来源光束、到处轮廓光和互相竞争的多光源。
- 用一个主色控制大面积，用一个辅色分离主体或托住环境。
- 不把霓虹、冷暖对撞、胶片色、雾和颗粒同时当作电影感捷径。

## 关键图提示词编译

先执行 `prompt-bible.md`；本节只提供关键图专项规则，不得覆盖提示词圣经的优先级和输出质检。

按以下顺序写成短而完整的自然语言，不把检查表原样塞给生成模型：

1. Asset 映射与画面主核。
2. 景别、机位、构图、人物关系与动作起点。
3. 有来源的主光和受控色彩关系。
4. 必要的材质或一种成像响应。
5. 连续性锁定和最多三条定向失败防护。

参考图已经锁定的信息使用 Asset ID 和用途说明，不用文字重新设计。关键图只负责静态起点；动作路径、运镜和终点留给 Clip。

## 修复流程

实际查看失败图后再修复：

1. 记录画面任务是否完成，以及最先抢走注意力的元素。
2. 区分剧情/导演设计、Asset 冲突、构图、人物状态、光线、色彩、成像响应和随机偏差。
3. 先删不服务主核的元素，再选择一项最小修改。
4. 保留已经成功的身份、关系、构图或光线，不整段重写。
5. 更新提示词版本，生成或交付后重新实际检查。

| 失败表现 | 优先修复 | 不要先做 |
|---|---|---|
| 画面杂乱 | 删除无关人物、道具、前景、粒子和背景细节 | 增加更多电影术语 |
| 主体不突出 | 拉开主体与背景的明暗、色彩、清晰度或遮挡层级 | 单纯把主体放大到满画面 |
| 人物僵硬 | 改一个可见状态、重心、视线或手部关系 | 堆叠多个表情和动作 |
| 光线虚假 | 改为一个有来源的主光并删除竞争光 | 增加光束和轮廓光 |
| 色彩太花 | 收敛为一个主色关系和一个辅助关系 | 再加一套冷暖或霓虹色 |
| AI 海报感 | 减少正面摆拍、机械对称、夸张姿势和全画面同等清晰 | 用更多“大片、震撼、高级”词 |
| CG 感 | 减少硬边、全局锐度、材质炫示和过强轮廓光，恢复现场光层次 | 用颗粒、雾和脏污遮盖问题 |

连续两三次出现同一问题时停止盲目重抽，重写对应条款或回到 Shot 设计。每次重试只改变一个主要变量，并记录结果。

## 静默检查

- 能否用一句话说清画面主核，且与 Shot 画面任务一致？
- 第一眼是否看向正确的人物、关系或道具？
- 所有元素是否具有剧情、空间、连续性或视觉组织功能？
- 主光是否有来源，主辅色是否受控？
- 关键图是否停在动作起点，没有提前完成 Clip 动作？
- 是否保留 Asset 硬锁定、多人物关系和项目画幅？
- 修复是否先删后加，并且本次只改一个主要变量？
