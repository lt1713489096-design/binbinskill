# 交付与成片复盘

## 交付层级

默认输出完整 Markdown 生产文档和 `project.json`。用户需要生产看板、复制提示词或团队审阅时，再生成 HTML；不要为简单分镜强制制作网页。

HTML 至少展示：项目摘要、场景诊断、资产、Beat、Shot、Clip、提示词版本、生成状态、实际终点、质检与修复结论。生成后实际渲染或检查：中文换行、宽表横向滚动、移动端可读、无重叠、无未替换占位符。

使用 `scripts/build_production_report.py project.json --output report.html` 生成基础报告。

## 视频复盘

收到成片或生成片段后必须实际查看画面与声音：

1. 读取时长、画幅、帧率和音轨。
2. 均匀抽帧并查看首帧、关键过程和末帧。
3. 有对白时读取或转写音频，检查对白、停顿和音画关系。
4. 对照 Shot/Clip 合同判断画面任务、导演意图、动作终点和连续性。
5. 选择保留、后期修复、局部编辑、同提示词重抽或重写提示词。
6. 接受后把实际终点写回 `project.json`；废弃结果不进入正式状态。

可先运行 `scripts/review_video.py <视频> --output-dir <目录>` 生成媒体信息、联系表和首末帧；需要转写时增加 `--transcribe`，本地缺少语音模型则继续做画面复盘并说明音频缺口。

## 最小重做

一次只改变一个提示词条款、参考资产、生成模式或随机结果。字幕、声音混合、裁切、少量首尾坏帧等后期问题不应牺牲已经成功的核心表演和构图。

检查方法：每个问题能否定位到 Beat、Shot、Clip、Asset、提示词版本和实际证据？不能时先补状态，不直接重做。
