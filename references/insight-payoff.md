## 使用边界

Insight 是观众在后续事件触发下，主动回想早先信息并得出新结论的时刻。它适用于隐藏身份、误会、真相重释、伏笔回收、地位逆转、讽刺和情绪兑现。

不要为每个故事强行设计打脸或反转。当情感价值来自陪伴、生活感、直线行动或清楚解题时，保留简单叙事。

人物能力提前出现、关系逐步变化、欲望找到新路径或开场建立气质，本身属于普通剧情的因果铺垫，不等于 Insight。只有存在有意知情差、误读、回溯点、揭示或公开兑现时才使用本参考；普通剧情读取 `setup-and-causality.md`。

| 旁观者 |  |  |  |  |

每次节拍只改变明确主体的知识状态。人物不得在没有观察、听到、推理或被告知的情况下突然获得信息。

## 三种 Insight 模式

### 观众知道，部分角色不知道

适用于隐藏身份、隐藏资源和地位逆转。快感来自观众的先知和对兑现的期待。

```text
建立真实身份/资源 -> 主角处于表面低位 -> 对手误读并越界 -> 回溯提示 -> 短暂延迟 -> 公开兑现/状态逆转 -> 新问题
```

期待已经非常强时不要无意义拖延。长篇中用小兑现、新代价或新误解维持进展，不用一个揭示拖到最后。

### 观众知道或怀疑是误会，角色持续错读

适用于误会喜剧、假权威和讽刺。过程本身是乐趣，可以延长，但每个新节拍必须增加新的误解、利益、尴尬、风险或讽刺层次。

```text
合理错位 -> 建立谁知道真相 -> 角色将异常重释为合理 -> 后果升级 -> 险些穿帮 -> 揭示或新后果
```

同一笑点、同一羞辱或同一期待只是重复时，立即压缩或结束。

### 观众也不知道完整真相

适用于隐藏动机、旧事真相、亲缘/身份秘密和早先行为重释。快感来自观众顿悟并重组已知信息。

```text
提供表面解释 -> 一个行为/台词/道具略显过量 -> 压力使其代价上升 -> 通过动作/图像补齐缺失真相 -> 观众回想早先信息 -> 情感后果/新目标
```

早先线索必须合理但稍显过量，能留下记忆又不像裸露设置。

## 伏笔、回溯点与兑现

- **伏笔**：一个具体的事实、动作、身份、道具、重复台词、怪异行为或视觉母题。
- **回溯点**：一个新事件、图像、台词、道具状态或危机，迫使观众重新理解伏笔。
- **兑现**：新理解带来的地位、风险、知识、关系或情绪结果。

三者必须建立可回收关系。伏笔不得只是模糊气氛，回溯点不得依赖角色长篇解释，兑现不得只停留在观众“知道了”而不改变戏剧条件。

## 节拍递进与时机

```text
建立 -> 压力/误读 -> 观众连接 -> 立即或延迟兑现 -> 后果 -> 新问题
```

- 观众已形成强烈兑现期待时，只为拖时间重复误读会消耗快感。
- 延迟必须增加风险、见证人、公开程度、代价或新误解。
- 兑现后必须给出反应、后果或新问题，不在揭示瞬间无因结束。
- 每个节拍至少改变地位、风险、知识或情绪压力中的一项。

## 视觉化揭示

优先用动作、道具、图像、环境变化或相同台词在新画面中重复来揭示真相。

- “同样的话，不同的画面”可让观众自行建立因果。
- 回溯点的景别、构图、声音或道具应与伏笔形成可识别对应。
- 不把所有因果都用闪回或哭诉解释；只补足观众无法合理推导的最小信息。

## 质检

- 是否存在具体伏笔，而不是模糊暗示？
- 观众和每个人物在各节拍知道什么？
- 哪个精确时刻促使观众回想伏笔？
- 伏笔是否可记但没有提前暴露？
- 延迟是否产生新价值，还是只在重复期待？
- 揭示是否主要通过画面和动作完成？
- 兑现是否改变地位、风险、知识、关系或情绪？
- 兑现后是否有后果或新问题？
