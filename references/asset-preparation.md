# 资产准备与静态提示词

## 适用范围

用于剧本转连续漫剧、需要角色/场景/道具参考图、现有资产不完整或生成前要建立资产库。已有可靠资产时只做映射和缺口检查，不重复设计。

## 资产准备流程

1. 读取剧本，提取人物、服装变体、场景、道具、可读文字和风格需求。
2. 为每项分配 Asset ID，标注来源事实、合理推导和设计建议。
3. 建立最低必要资产，不为只出现一次且无特写的背景物制作独立资产。
4. 输出静态图片提示词；用户需要英文时再附英文，默认中文平台中立。
   Shot 关键图同时按 `key-image-restraint-and-repair.md` 锁定画面主核与复杂度预算；角色标准图、场景设定图和道具设定图不强行套用单镜头预算。
5. 实际查看生成结果，记录硬锁定、可变项、适用时段和禁止迁移内容。
6. 更新 `project.json` 后才开始 Shot 与 Clip 编译。

## 静态提示词结构

```text
Asset ID 与用途
主体身份/动作或标准姿态
地点与时代背景
构图、视角和画幅
有来源的光线与色彩
服装/材质/磨损/尺度
镜头或焦段空间感
硬锁定与允许变化
禁止错误文字、额外人物、身份漂移和无依据装饰
```

角色标准图优先清楚身份、比例、发型、服装层级和识别特征；场景图优先入口、路径、活动区、主光源和可重复机位；道具图优先功能、尺寸、轮廓、材质、持握和剧情状态。

## 参考用途

每份参考只分配一个主要用途：身份、服装、场景结构、道具、构图、动作、镜头节奏、光线、色彩、质感或终点。明确“不得迁移”的内容，例如风格图中的人物服装不得覆盖角色资产。

## 资产 QA

- 文件内容与 Asset ID 是否一致。
- 角色、场景、道具是否存在互相冲突的硬锁定。
- 变体是否有明确生效时段。
- 可读文字是否应后期制作而非交给图像模型。
- 当前平台参考位不足时，是否优先保留最难文字化的硬资产。

只有高风险身份歧义才询问用户；文件映射明确时自动继续。
