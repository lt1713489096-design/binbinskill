# 剧本到分镜交接

## 边界

本 Skill 不复制完整编剧流程。剧本已经成立时，只提取镜头所需的结构事实；如果核心因果、人物目标或场景价值不成立，交给 `screenwriting-master` 修订后再分镜。

## 场景交接卡

每场至少记录：

- 场景 ID、地点、时间和人物。
- 本场结构功能：建立、推进、转折、危机、高潮、收束或过渡。
- 进入价值 -> 触发动作 -> 退出价值。
- 主角目标、直接障碍、可观察尝试和结果。
- 上一场什么结果导致本场；本场什么结果推动下一场。
- 必须完整保留、允许压缩和允许改写的对白范围。
- 不可改变事实、目标时长和必要视听线索。

## 因果审计

逐场问：“本场发生，是因为上一场发生了什么？”若只能回答“然后又发生”，标记因果缺口。删除本场后结局、人物选择或信息状态完全不变时，检查是否为废场或可合并过渡。

## 轻度修补权限

允许为镜头成立而合并重复信息、把内心描述改为动作、调整对白落点和拆分过长节拍。不得擅自改变人物动机、核心因果、高潮选择和结局。

## 分流

- 小范围可视化问题：本 Skill 直接修补并记录。
- 场景目标、因果、价值转变不成立：调用 `screenwriting-master`。
- 明确要求打分、结构诊断或剧本医生：优先使用编剧 Skill，不在分镜模板中复制量化评分。

检查方法：每个 Beat 是否能回到场景交接卡；所有镜头变化是否仍服务进入/退出价值和因果链？
