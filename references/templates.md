# 通用生产输出模板

## 输出顺序

1. 项目摘要与预检
2. 场景四维诊断
3. 剧本交接卡与 Beat 表
4. 普通剧情铺垫或 Insight（按需）
5. Asset 表
6. Shot 表与导演记录
7. 关键图提示词
8. Clip 编译表与视频提示词
9. 视听、连续性与生成质检
10. 版本和实际终点记录

机器事实写入 `project.json`；以下 Markdown 是面向人阅读的派生文档，不另行维护冲突状态。

## 关键图提示词

输出前先通过 `prompt-bible.md`；以下结构是提示词圣经的关键图分支。

```text
【Shot与版本】
Sxx，[画幅]，关键图提示词 vN。

【Asset映射】
[逐项写明参考用途和禁止迁移项。]

【画面任务与导演意图】
[静音必须看懂什么；构图如何服务意图。]

【画面主核与复杂度预算】
[谁/什么，在什么环境里，处于什么可见状态；主要视觉焦点、必要人物/道具/前景及各自功能。]

【构图与权力空间】
[主视角、所有者、镜头身份、凝视目标及成立证据；景别、机位、人物屏幕位置、遮挡、中心控制、轴线、运动余量、字幕安全区。]

【动作起点与表演】
[只写一个主体动作的起始状态、重心、眼神、手势和道具状态。]

【光线与风格】
[主光来源/方向/软硬；一个主色关系加最多一个辅助关系；必要材质或一种成像响应。]

【连续性与禁止】
[身份、造型、空间、道具、方向、时间、天气、光源；最多三条针对当前失败的定向约束，不得误删剧情所需人物。]
```

## 视频提示词

输出前先通过 `prompt-bible.md`；以下结构是提示词圣经的视频分支。

```text
【Clip与版本】
Cxx，[画幅]，[预计时长]，视频提示词 vN。

【参考调度与全局锁定】
[Asset ID/平台编号、主要用途、生效范围、必须迁移、允许变化、禁止迁移。]

【完成边界】
必须发生：[一项核心变化。]
不得发生：[后续动作、提前揭示或额外行为。]

【时间脚本】
[起止秒或归一化阶段] Sxx｜主体与空间｜准备/执行/落定｜视角景别机位｜主运镜及触发｜台词/声音｜本段终点。
[按顺序继续；覆盖全时长，不重叠、不留无说明空档。]

【动作余势】
[准备 -> 执行 -> 落定；姿势、速度、方向和道具关系连续，不复位。]

【连续性与末帧】
[承接上一接受Clip的实际终点；身份、空间、方向、道具、光线稳定；末帧保留下一Clip可用锚点。]

【定向稳定约束】
[只写当前风险，最多三条；不得机械追加通用稳定咒语。]
```

## 质检报告

```markdown
# 生产质检

## 整体判断
- 静音是否能看懂目标、障碍和变化：
- 场景四维诊断是否贯穿镜头：
- 声音是否增强而非替代画面：
- 最优先修复层级：[剧本/导演设计/Asset/Shot提示词/Clip提示词/生成/剪辑]

## 提示词圣经
- 提示词类型是否正确，关键图与视频职责是否混淆：
- 是否只有一个画面任务：
- 每份参考是否有用途、生效范围和禁止迁移：
- 时间脚本是否覆盖全片且准备—执行—落定连续：
- 是否存在动作复位、运镜堆叠或抽象情绪替代：
- 首帧是否承接实际末帧，末帧是否可供下一段使用：
- 稳定约束是否针对当前风险且不超过三条：
- 是否含平台混写、重复画质词或冲突指令：

## 问题表
| Beat/Shot/Clip/Asset | 问题类型 | 观众可能误读 | 实际证据 | 最小修复 | 五级处置 | 是否重生成 |
|---|---|---|---|---|---|---|
| Sxx |  |  |  |  | 保留/后期/局编/重抽/重写 |  |

## 连续性
- 静音时能否判断是谁或什么在看：
- 角色直视镜头时，能否判断其看的是故事人物、设备还是现实观众：
- 去掉运镜后是否损失新信息、关系、情绪推进或空间建立：
- 屏幕左右、视线、轴线和运动方向：
- 场景、门窗、道具和权力空间：
- Shot入口/出口锚点：
- 特殊转场的意图、隐藏剪切窗口和主匹配条件：
- 遮挡完整性/甩镜同向性/动作同相位/构图同关系：
- 切点是否出现方向反转、速度突变、动作重启、主体跳位或比例弹跳：
- Clip内部时长及末帧：
- 接受成片实际终点是否写回项目：

## 分流与铺垫
- 普通剧情是否被无授权爽文化：
- 铺垫承诺是否由行动验证：
- 权力变化与行为惯性是否分开：
- Insight存在时是否单独记录知情差和兑现：

## 平台与资产
- 平台限制是否有验证日期和来源：
- 是否混入其他平台语法：
- 每份参考是否有主要用途和禁止迁移项：
- 缺失资产是否真的阻塞当前Shot：

## 关键图克制与修复
- 画面主核是否能用一句可见事实说清：
- 第一眼是否落在正确人物、关系或道具：
- 是否存在不服务剧情、空间、连续性或观看顺序的元素：
- 主光是否有来源，主辅色是否受控：
- 是否停在动作起点，没有提前完成Clip动作：
- 失败修复是否先删后加且只修改一个主要变量：
```
