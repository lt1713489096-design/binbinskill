## 剧情节拍与画面任务

剧情节拍不是台词段落或知识主题，而是一次可观察的变化：人物得到信息、目标受阻、关系改变、做出选择、力量逆转、危险出现或情绪转向。

每个节拍写成：

```text
节拍前状态 -> 触发动作/信息 -> 节拍后状态
```

画面任务回答：“观众不听对白也必须看懂什么？”使用可观察表述，不写“他意识到”“她感到害怕”等内心判断。改写为目光、停顿、重心、距离、手部动作、道具状态或行动选择。

一个镜头无法清楚完成两个变化时，拆为两个 Shot。两个相邻 Shot 表达同一信息且没有新的情绪或关系变化时，合并或删除其中一个。

## 导演意图一致性

在选择景别前，用一句可验证的话说明本 Shot 要让观众经历什么，例如“从掌控感转为被威胁”或“让拒绝比对白更明确”。导演意图不是“电影感、震撼、唯美”等效果词，也不重复剧情梗概。

景别、机位、光线、站位、表演、运镜和声音必须共同服务该意图。出现互相竞争的设计时，保留最能完成画面任务的选择，其余简化。

例外：有意使用画声错位、反讽或表面平静与内在危险的反差时，各层可以不同向，但组合后仍必须产生同一个明确效果。

检查方法：逐项追问“去掉或替换这个选择，导演意图是否变弱？”若没有变弱，该选择可能是装饰；若某项制造相反理解，重新设计或明确反差目的。

## 景别、机位与构图

| 选择 | 主要作用 | 常见误用 |
|---|---|---|
| 远景/大全景 | 建立地点、规模、路径和人物空间关系 | 空间已经清楚后反复交代 |
| 全景 | 展示全身动作、多人调度和环境约束 | 用于需要细微表情的信息 |
| 中景 | 表现对话、人物关系和清楚的身体动作 | 全片保持同一中景而没有重点 |
| 近景 | 强调反应、决定、关系压力或关键信息 | 未建立人物和地点就无目的贴脸 |
| 特写/大特写 | 放大关键眼神、动作、线索或情绪转折 | 只为冲击力而使用 |
| 插入镜头 | 交代道具状态、手部动作、信号或证据 | 展示不改变剧情的装饰细节 |
| 过肩/正反打 | 建立对话方向、距离与权力关系 | 双方视线相同或无意越轴 |
| 高机位 | 表现弱小、暴露、受控或空间结构 | 默认把角色拍得可怜 |
| 低机位 | 表现压迫、力量、威胁或主导 | 默认英雄化所有角色 |
| 平视 | 中性、平等、生活感和表演优先 | 把中性误写成无设计 |

新场景先建立观众理解当前动作所需的最少空间信息。可以用近景或特写开场，但必须服务于隐藏、惊吓、主观感受或线索揭示，并在后续镜头及时恢复空间关系。

构图必须明确主体位置、视觉重量、前中后景、视线空间、运动余量和字幕安全区。景别与角度变化必须增加新信息、情绪或关系，不做无意义换机位。

视角身份、凝视关系、人物/物品 POV 和第四面墙按 `viewpoint-and-gaze-design.md` 设计。景别、机位、直视镜头、手持和鱼眼不得替代视角归属。

## 空间语法

### 轴线与视线

- 对话、对峙或共同动作先建立 180°轴线，保持人物稳定在各自屏幕侧。
- A 看画面右侧时，B 通常看画面左侧；视线高度与人物相对位置匹配。
- 越轴前使用中性正面镜头、沿轴镜头、可读的环绕过程或重新建立空间的全景。
- 有意错视线或越轴只能用于疏离、迷失、关系断裂等明确效果，并在提示词和质检中标记。

### 运动方向

- 人物向画面右侧离开后，下一镜通常继续向画面右侧运动。
- 场景或时间改变时，用建立镜头、中性运动、明确转身、门/路径或声音桥重置方向。
- 追逐、对冲和远离关系必须给各角色固定方向，避免同向镜头被误读为相互靠近。

### 道具与场景地理

- 锁定门、桌、道路、光源、关键道具和人物之间的位置关系。
- 锁定道具由哪只手持有、朝向、开合、损坏和使用状态。
- 下一镜从上一镜动作终点开始，不无意重复、跳过、倒退或交换位置。

## 主体动作与镜头运动

主体动作写清：谁先动、动作起点、路径、幅度、速度、与谁或什么发生关系、动作终点。优先使用一个可完成的动作，不让多人同时执行复杂动作。

固定镜头也是明确的导演选择。表演和信息足以完成节拍时，优先固定镜头。

| 运镜 | 叙事作用 | 使用边界 |
|---|---|---|
| 推近 | 接近发现、威胁、决定或情绪 | 从可读空间推到明确重点 |
| 拉远 | 揭示孤立、后果、尺度或失控 | 人物动作保持简单 |
| 摇/俯仰 | 跟随或揭示初始画外信息 | 一次只揭示一个重点 |
| 跟拍/横移 | 陪伴人物穿过有意义的空间 | 保持主体位置和真实视差 |
| 升降 | 从人物扩展到空间，或从全局落到人物 | 运动路径连续，不突然改向 |
| 弧线/环绕 | 表现关系、认知或力量变化 | 只用于强节拍，保持轴心和透视 |
| 手持 | 紧张、临场和不稳定感 | 幅度受控，不以乱晃代替紧张 |
| 固定 | 让表演、构图或事件成为重点 | 避免误把固定理解为没有设计 |

运镜必须写清起始景别与机位、运动起点、路径、速度或时长、终点以及叙事作用。复杂动作配简单镜头；复杂运镜配简单动作。禁止无叙事依据的连续旋转、鱼眼、瞬移、突然变焦和无惯性启停。

把运动路径、跟随关系和稳定方式分开：跟拍可以同时推近，手持可以用于客观或主观视角，但一个 Shot 只保留一种主运动路径。推近终点必须落到新重点；拉远必须释放新空间或后果；横移与摇镜必须揭示新关系；固定镜头由人物调度、光线或环境承担变化。

## 剪辑关系

每个 Shot 同时设计入口锚点与出口锚点：

- 入口可以承接动作、视线、声音、构图、形状、方向、道具状态或地点揭示。
- 出口可以是完成的动作、保持的反应、投向画外的视线、提前进入的声音、稳定构图或清晰道具状态。
- 在新信息、动作完成、选择发生或情绪改变处剪切，不按任意秒数机械切镜。
- 反应镜头必须展示事件造成的后果，不用作填充。
- 匹配剪辑必须保持动作、形状、速度或方向中的主要匹配条件。
- 声音可以先于下一镜进入或延续到下一镜，但必须说明它在叙事中的作用。

遮挡、甩镜、动作匹配和构图匹配等特殊转场按 `transition-design-and-cut-bridges.md` 建立转场合同。不得仅凭“相似”判断成立：动作匹配检查动作相位，构图匹配检查屏幕位置、比例、角度与几何关系。

## 段落级视听策略

先确定段落要表达的概念、关系或节奏，再选视听形式。不得因为“想用某种技巧”而倒推剧情。一个短段落通常聚焦 1–2 种核心手法，并让手法随信息递进、变异或在关键处被打破。

| 策略 | 适用任务 | 约束 |
|---|---|---|
| 交叉剪辑 | 并行动作、对比、期待两线交汇 | 两线节奏和方向关系必须可读 |
| 跳切蒙太奇 | 压缩重复行动和长时间变化 | 保持一个稳定构图或动作基准 |
| 分屏 | 同时展示对比或并行空间 | 每个区域任务清楚，不用于无关信息堆叠 |
| 前景/背景并置 | 在同一镜头中展示两层信息 | 主次关系和观看顺序必须可读 |
| 固定机位时间变化 | 展示空间不变与人/时间改变 | 固定视角本身要承担对比任务 |
| 画声错位 | 讽刺、反差或补充画外信息 | 两层信息需产生明确关系 |
| 静默 | 在高密度后强调反应、真空或不可言说的变化 | 静默时画面必须有可读行动或状态 |

选择后检查：去掉该形式时，叙事、观众体验或信息关系是否明显变弱？若没有，改用更简单的形式。

## AI 生成边界

- 关键图负责身份参考、静态构图、站位、视线、道具状态、光线和动作起点。
- 关键图按 `key-image-restraint-and-repair.md` 控制画面主核、复杂度、主光和色彩；多人关系镜头按关系焦点组织，不机械删减人物。
- 图生视频负责主体动作、环境运动、镜头运动、节奏、动作终点和稳定约束。
- 参考图负责锁定身份和资产；文字不得重新设计已锁定的人物、服装、道具和场景。
- 一镜只完成一个画面任务、一个主要动作和一种主运镜。
- 不让末帧提前完成下一镜动作，保留稳定拼接锚点。
- 不写模型无法观察的内心活动，不用抽象形容词替代动作和空间。
- 不因追求“电影感”堆叠运镜、光效、粒子、镜头术语和画质词。

## 视听语法质检

### 静音检查

- 是否能用一句话说清本 Shot 的导演意图，且构图、站位、表演和运镜共同支持它？
- 能否识别地点、出场人物、人物关系、目标、障碍和本镜变化？
- 人物屏幕侧、视线、轴线、运动方向和相对距离是否一致？
- 道具、门、道路、光源和动作终点是否连续？
- 景别、机位和运镜是否增加信息或情绪？
- 是否存在重复信息、无任务镜头或把下一镜动作提前完成的末帧？
- 静音时能否判断视角所有者；角色直视镜头时能否判断其凝视对象？
- 去掉运镜后是否损失新信息、关系、情绪推进或空间建立？

### 带声音检查

- 声音是否支持同一导演意图；若有画声反差，反差结果是否清楚？
- 台词、动作、音乐和音效是否在同一节拍上互相强化？
- 声音桥、重音和停顿是否支持剪辑，而不是掩盖画面不清？
- 去掉解释性台词后，核心剧情是否仍然成立？
- 镜头时长是否由动作、信息和情绪完成决定？

### 报告方式

按 Beat/Shot/Clip/Asset ID 记录：问题类型、观众可能误读的内容、问题所在层级、最小修复动作和是否需要重生成。优先修复导演设计，其次修复关键图、Clip 提示词、生成片段或剪辑；不要无差别重做整段。
